# HOMIZ - User Stories

1. As a visitor, I want to browse projects, so that I can see different interior designs.

2. As a visitor, I want to view designers, so that I can find a designer.

3. As a visitor, I want to view services, so that I can see what the platform offers.

4. As a user, I want to create an account, so that I can use the platform.

5. As a designer, I want to create a project, so that I can show my work.

6. As a designer, I want to view my projects, so that I can manage them.

7. As a designer, I want to edit my projects, so that I can update them.

8. As a designer, I want to delete my projects, so that I can remove them.
